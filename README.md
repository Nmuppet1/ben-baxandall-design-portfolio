# Ben Baxandall- Design Portfolio

I want to make a professional portfolio to show my design skills. I want the page to be very minimal to start. The page will start at the bottom and scroll up. At the bottom will be my name and saying enthusiast in... there will be no scroll wheel, i want the page to have climbing holds which have random placements and sizes and the user drags them down to pull themselves up the screen. I want some friction to feel like your actually climbing and some good animation. As you go up, it reveals tabs and these can be pulled across to the side like a blind to reveal a page like projects or skills pages. I want the code to be extremely simple and a dark theme with simple black for now
